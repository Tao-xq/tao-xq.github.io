# Rest Mode

一个可以停下来聊聊喜欢的作品、写点日常的小站。

[打开网站](https://tao-xq.github.io/) · [我的 GitHub](https://github.com/Tao-xq)

这里是桃子qwq的个人 ACGN 小站。动漫、漫画、游戏、小说，或是生活里的一点小发现，都可以拿来聊聊。欢迎温柔友好地分享，也欢迎只是来海边坐一会儿。

## 在这里逛逛

- **次元闲谈**：大家一起分享喜欢的作品和有趣的事，可以发图文帖子，也可以按关键词或作者搜索。新帖子排在前面，展示浏览量，没有点赞和评论。
- **日常随笔**：放我的个人文章、About 和朋友们的链接。
- **窗边便签**：留一句短短的话。点击首页挂着的便签就能看到大家的留言，左下角的「＋」可以写新留言。

首页是一间面朝海边的小房间，有看书的女生、睡觉的小猫和慢慢拍岸的海浪。点击太阳或雨云可以切换天气；天气和中、英、日界面语言的选择都只保存在你自己的浏览器里。

帖子会先显示原文。需要时再点击「翻译」，可以选择中文、英语或日语，也可以对照原文阅读。译文会注明来源，不会改动作者写下的内容。

## 发帖和头像

点击首页左上角的写作图标，就可以上传封面、填写昵称和正文，发布到次元闲谈。写作区支持常用文字排版、图片和链接，草稿保存在当前浏览器中。

目前无需注册。网站通过浏览器中的匿名会话识别作者，所以请在原来的浏览器里编辑自己的帖子；换设备或清除浏览器数据后，编辑权限暂时无法自动找回。

发帖和写留言时可以设置自己的头像。没有设置的话，会从八个小图案中分配一个，同一身份的帖子和留言会使用相同头像。

## 更新网站内容

我的个人随笔和资料通过这个仓库维护，提交到 `main` 后会自动发布到网站。

| 要更新的内容 | 文件位置 |
| --- | --- |
| 昵称、头像、GitHub 链接、三种语言的 About、友链 | [content/owner.json](content/owner.json) |
| 个人随笔及校对好的译文 | [content/daily/](content/daily/) |
| 文章配图和其他图片 | [web/assets/](web/assets/) |

文章格式、后台配置和日常管理方法见 [维护说明](docs/maintenance.md)。

## 本地运行

使用 Node.js 24，在仓库目录运行：

```sh
npm ci --ignore-scripts
npm run build
node scripts/serve.mjs
```

然后打开 [本地预览](http://127.0.0.1:4173/)。修改后重新构建即可看到更新，按 `Ctrl+C` 停止预览服务。运行 `npm test` 可以检查现有的安全和头像功能测试。

网站前端使用 HTML、CSS 和 JavaScript，通过 GitHub Pages 发布；访客帖子、留言、图片和浏览量由 Supabase 保存，按需翻译使用 DeepL。前端构建结果放在 `dist/`，不需要手动提交。
